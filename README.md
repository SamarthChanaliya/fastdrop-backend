# FastDrop — Backend 🚀

FastDrop is a **classroom-first file sharing system** built for labs, workshops, and teaching environments.

This repository contains the **Spring Boot backend** for FastDrop, developed as a **college problem-solving project**.  
It powers instant sharing of files, links, code, and notes **inside a classroom**, without personal apps or logins.

---

## The Problem 🎓

Most classrooms rely on WhatsApp or personal messaging apps for sharing materials.
This mixes academic work with private spaces, creates privacy risks on shared computers, and disrupts teaching flow.

Classrooms deserve tools built for learning—not workarounds.

---

## The Idea 💡

FastDrop creates a **shared, temporary classroom space**:
- 🚫 No accounts or personal logins
- ⚡ Instant access for everyone in the room
- 👩‍🏫 Faculty stays in control
- 🧠 Sharing stays focused on learning

It’s infrastructure, not another distraction.

---

## Tech Stack 🛠️

- **Spring Boot** — Backend & REST APIs
- **Supabase** — Database and backend services
